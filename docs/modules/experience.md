# Experience Module

## Purpose

Define journey and rhythm before composition.

## Responsibilities

Model journey stages, attention curve, trust curve, CTA cadence, proof placement, content density curve, media rhythm, interaction rhythm, scroll narrative, mobile journey, and conversion friction points.

## Inputs

Business intelligence, brand intelligence, content strategy, conversion goals, accessibility constraints, repository experience patterns.

## Outputs

`ExperienceStrategy` and trace decisions.

## Public Interface

`runExperienceEngine(input): EngineResult<ExperienceStrategy>`.

## Dependencies

SDK, content intelligence, repository, trace.

## Lifecycle

Runs before Pattern Intelligence, Reasoning, Decision Engine, Compiler, Simulation, and Critic.

## Example Flow

Real estate builds from aspiration to proof to site visit; healthcare builds trust before appointment; restaurant moves appetite to menu to booking; automotive moves browse to proof to test-drive; education moves aspiration to programs to admissions.

## Known Limitations

Does not map components.
