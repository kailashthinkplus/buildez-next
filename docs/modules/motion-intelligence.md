# Module: Motion Intelligence

## Purpose

Define motion language before implementation.

## Output

`MotionStrategy`.

## Responsibilities

- Define motion tone, pacing, transition intent, scroll rhythm, parallax intent, interaction response, reduced-motion behavior, and accessibility limits.
- Avoid selecting GSAP, Framer Motion, Lottie, Rive, Three.js, Spline, Higgsfield, or any provider as the strategy.

## Examples

Real estate uses calm premium parallax intent; healthcare uses minimal low-anxiety motion; restaurant uses sensory reveal; automotive uses precise performance motion; education uses guided progression; hospitality uses immersive booking-safe motion; interior design uses refined portfolio reveals; D2C uses product micro-motion.
