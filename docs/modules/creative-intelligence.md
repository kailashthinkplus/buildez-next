# Module: Creative Intelligence

## Purpose

Create provider-agnostic art direction from business, brand, content, experience, pattern, and design inputs.

## Inputs

- `BusinessIntelligenceProfile`
- `BrandIntelligenceProfile`
- `ContentStrategy`
- `ExperienceStrategy`
- `PatternIntelligenceResult`
- `DesignResult`
- repository records
- asset inventory
- missing facts/assets

## Output

`CreativeIntelligenceProfile`.

## Responsibilities

- Coordinate Inspiration, Visual Mood, Media Intelligence, Motion Intelligence, and Provider Abstraction.
- Produce art direction without rendering or provider calls.
- Keep provider requests bounded and replaceable.
- Preserve Builder editability requirements.

## Non-Goals

No Higgsfield implementation, API calls, DB, network, CSS, rendering, components, composition, Builder nodes, or production wiring.

## Examples

Real estate uses editorial luxury art direction; healthcare uses calm clinical clarity; restaurant uses warm sensory ambience; automotive uses precision; education uses accessible aspiration; hospitality uses immersive destination warmth; interior design uses portfolio materiality; D2C uses product-led clarity.
