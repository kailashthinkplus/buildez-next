# Module: Media Intelligence

## Purpose

Declare media requirements before any asset generation, sourcing, or rendering.

## Output

`MediaStrategy`.

## Responsibilities

- Define required images, videos, icons, maps, diagrams, documents, and 3D assets.
- Mark missing assets explicitly.
- Define fallback policy and provider suitability.
- Preserve native Builder editability.

## Examples

Real estate requires project/gallery/location assets; healthcare requires clinic/provider assets only if provided; restaurant requires menu/ambience/location media; automotive requires vehicle/service media; education requires program/campus/faculty media; hospitality requires rooms/amenities/destination assets; interior design requires portfolio/process media; D2C requires product/detail/lifestyle assets.
