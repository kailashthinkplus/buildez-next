# RC-3.5B Universal Native Widget Population Engine

RC-3.5B introduces immutable production population contracts, declarative industry-role policies, dedicated population compilers, verified-fact gating, deterministic presentation exploration, and default/demo leakage validation.

The engine lives under `website-engine/builder-blueprint/widget-population/` and is invoked by `compileNativeVisualCapability` before semantic hydration. It supports hero, carousel, gallery lightbox, FAQ, lead form, timeline, logo cloud, smart footer, floating WhatsApp, and CTA.

Contracts are derived from registered production capability and Inspector behavior. Flat editable properties remain intact. Initial nested structures carry stable IDs and semantic slots for RC-3.5C; no factual content is invented. Logo cloud requires verified logo assets and floating WhatsApp requires a verified destination. Missing facts reject compilation with a role-correct replacement recommendation.

Five industry policies express preferences rather than fixed templates: real estate, healthcare, SaaS, hospitality, and automotive. Population content is section-scoped and model-hydratable; production source contains no benchmark business, seed, or copy.

Focused population and semantic compiler tests pass. Repository-wide TypeScript remains blocked by pre-existing syntax errors in `modules/_legacy/modules.old/blueprint/*.ts` and `builder-v2/sidebar/panels/BlocksPanel.tsx`.
