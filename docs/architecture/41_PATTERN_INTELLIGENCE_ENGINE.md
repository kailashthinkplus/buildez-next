# Pattern Intelligence Engine

## Purpose

Pattern Intelligence reasons about semantic patterns. It is not template selection.

## Responsibilities

Determine which semantic patterns fit the website goal, satisfy trust, satisfy conversion, fit brand, fit design language, are forbidden, are overused, conflict, or combine into the best journey.

## Pattern Examples

Editorial Hero, Trust Band, Proof Stack, Booking Path, Menu Preview, Project Showcase, Service Matrix, Outcome Proof, Locality Map, FAQ Objection Handling, Final Conversion Block, Comparison Section, Gallery Narrative, Founder Story, Case Study Teaser.

## Inputs

Business intelligence, brand profile, content strategy, experience strategy, repository patterns, constraints, design language, and prior pattern rankings.

## Output

`PatternIntelligenceResult`.

## Multi-Industry Examples

- Real estate: Project Showcase, Gallery Narrative, Locality Map, FAQ Objection Handling, Final Conversion Block.
- Healthcare: Trust Band, Provider Proof Stack, Service Matrix, Booking Path, FAQ Objection Handling.
- Restaurant: Editorial Hero, Menu Preview, Gallery Narrative, Locality Map, Booking Path.
- Automotive: Catalogue/Comparison Section, Service Matrix, Proof Stack, Booking Path, FAQ Objection Handling.
- Education: Outcome Proof, Program Matrix, Admissions Journey, Founder/Faculty Story, Final Conversion Block.

## Failure Modes

- Selecting a template because the industry label matches.
- Overusing card grids.
- Combining patterns that conflict in density, trust posture, or CTA cadence.

## Implementation Guidance

Pattern intelligence should produce semantic recommendations and rejections. Reasoning ranks these signals and the Decision Engine commits compatible strategy choices before compiler/component mapping.
