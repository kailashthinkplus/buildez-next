# Higgsfield MCP Strategy

## Position

Higgsfield MCP is an optional creative provider, not a BuildEZ engine and not the source of truth.

BuildEZ owns:

- business strategy
- brand strategy
- content truth
- experience rhythm
- pattern selection
- design intent
- creative strategy
- component and composition rules
- native Builder editability

Higgsfield may execute bounded cinematic/media/motion tasks when an adapter is explicitly implemented in a future phase.

## Suitable Tasks

Potential future uses:

- cinematic visual concepts
- image/video style exploration
- parallax idea generation
- motion reference clips
- product or space presentation concepts
- mood exploration assets

## Unsuitable Tasks

Higgsfield must not decide:

- which industry or archetype the site is
- what claims are true
- which components to use
- final page structure
- Builder node output
- compliance posture
- conversion strategy

## Editability Requirement

Any Higgsfield output must be converted by BuildEZ into editable native Builder assets or nodes. A cinematic artifact may inspire or supply a media asset, but it cannot replace structured, editable website output.

## Examples

- Real estate: generate a cinematic mood reference for project-gallery motion from provided assets.
- Healthcare: avoid patient or credential fabrication; use only abstract calm motion references.
- Restaurant: ambience treatment from supplied dining imagery.
- Automotive: performance-style motion reference without false authorization/inventory claims.
- Education: aspirational campus mood only with provided campus media.
- Hospitality: destination mood video concept from provided property assets.
- Interior design: material-focused portfolio transition reference.
- D2C: product-focused motion concept using provided product media.
