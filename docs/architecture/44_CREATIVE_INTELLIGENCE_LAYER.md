# Creative Intelligence Layer

## Purpose

Creative Intelligence turns business, brand, content, experience, pattern, and design intent into art direction. It is the missing strategy layer between deterministic website intelligence and future media, motion, component, and composition execution.

## Core Rule

BuildEZ owns creative strategy.

Providers such as Higgsfield MCP, GSAP, Framer Motion, Three.js, Spline, Rive, Lottie, or future tools only execute bounded visual, media, or motion tasks. No provider decides business strategy, `WebsiteSpec`, component selection, page structure, conversion goals, proof claims, or final Builder node shape.

## Responsibilities

- Produce `CreativeIntelligenceProfile`.
- Coordinate inspiration, mood, media, and motion strategy.
- Convert Design Engine intent into art direction.
- Define media and motion needs before Component or Composition engines.
- Keep provider requests replaceable and traceable.
- Preserve editability: provider outputs must be converted into native Builder assets, tokens, patterns, or editable node structures later.

## Subsystems

1. Inspiration Engine: metadata about references, styles, eras, visual analogies, and constraints. Inspiration is not copying websites.
2. Visual Mood Engine: emotion, lighting, depth, texture, camera, material, contrast, and image style.
3. Media Intelligence: required images, videos, icons, maps, diagrams, documents, and possible 3D assets.
4. Motion Intelligence: motion language, pacing, transitions, parallax intent, reduced-motion policy, and interaction timing.
5. Creative Provider Abstraction: provider-neutral request/result contracts.
6. Higgsfield MCP Strategy: optional provider strategy for cinematic visual/media/motion tasks.

## Lifecycle Position

```txt
Business Intelligence
-> Brand Intelligence
-> Content Intelligence
-> Experience Engine
-> Pattern Intelligence
-> Design Engine
-> Creative Intelligence
-> Component Engine
-> Composition Engine
-> Compiler revisit
```

## Multi-Industry Examples

- Real estate: editorial/luxury inspiration, warm neutral cinematic mood, project/gallery/location media needs, calm parallax intent.
- Healthcare: clinical/reassuring inspiration, high-clarity low-anxiety mood, provider/location/service images, minimal motion.
- Restaurant: hospitality/warm inspiration, sensory lighting and texture, food/menu/interior media, gentle ambience motion.
- Automotive: industrial/technology inspiration, high-contrast precision mood, vehicle/service/process media, performance-safe motion.
- Education: warm/corporate inspiration, aspirational but accessible mood, campus/program/faculty media, calm guided motion.
- Hospitality: immersive destination inspiration, warm cinematic mood, rooms/amenities/location media, booking-friendly motion.
- Interior design: editorial/minimal inspiration, material/space/camera mood, portfolio/process media, refined reveal motion.
- D2C: product-led inspiration, category-specific mood, product/detail/lifestyle media, purchase-supporting micro-motion.

## Non-Goals

- No provider API calls.
- No Higgsfield MCP implementation.
- No CSS, rendering, Builder nodes, final components, or generation.
- No copying competitor websites.
- No LLM or external-service dependency.
