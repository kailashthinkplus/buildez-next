# ADR: Pattern Intelligence Over Template Selection

## Status

Accepted

## Context

The engine needs reusable pattern reasoning across industries.

## Problem

Template selection from an industry label is brittle and non-universal.

## Decision

Create Pattern Intelligence to reason about semantic patterns, conflicts, overuse, trust, conversion, brand fit, design fit, and journey fit before component selection.

## Alternatives Considered

- Select templates by industry. Rejected.
- Let resolver infer semantic pattern needs. Rejected because pattern reasoning deserves a distinct traceable stage.

## Consequences

Pattern decisions become explainable and reusable.

## Future Implications

Learning can rank semantic patterns independent of component implementation.
