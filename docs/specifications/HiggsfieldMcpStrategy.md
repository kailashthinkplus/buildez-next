# HiggsfieldMcpStrategy

## Purpose

Documents Higgsfield MCP as an optional creative provider strategy.

```ts
export interface HiggsfieldMcpStrategy {
  enabled: false;
  providerRole: 'optional_execution_provider';
  allowedTasks: string[];
  forbiddenDecisions: string[];
  requiredInputs: string[];
  outputHandling: 'convert_to_native_builder_or_reference_only';
}
```

## Allowed Future Tasks

Cinematic assets, visual concepts, parallax references, motion reference clips, and media treatments from provided assets.

## Forbidden Decisions

Business strategy, WebsiteSpec, final structure, component selection, claims, compliance, and Builder nodes.
