# DesignDNA

## Purpose

`DesignDNA` is a deterministic visual identity contract for one generated website.

## Required Axes

- grid system
- whitespace level
- asymmetry level
- visual hierarchy
- typography rhythm
- image crop strategy
- media ratio
- card ratio
- radius system
- shadow language
- border language
- depth strategy
- glass usage
- background language
- CTA style
- section rhythm
- scroll rhythm
- motion rhythm
- editorial level
- luxury level
- density level
- uniqueness score
- diversity seed

## Rules

- No randomness.
- Diversity seed is deterministic from input metadata.
- Metadata only.
- No rendering, generated UI, Builder nodes, provider calls, or production wiring.
